Tap a hexagon.
Terrain is sampled from each cell's real 3D position on the sphere, with the noise function doc 08 pins — so it flows straight across a face seam without knowing one is there. Chunk lines are teal; the tapped cell's own chunk is filled, and the nested triangles show the path digits that name it, one per level. A cell sitting on a seam has a name in each face it touches; doc 03 awards it to the lowest chunk ID, which is what you are shown.
